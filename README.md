## 🚀 Featured Projects

### 🛰️ SENTINEL — Public Health Signal Intelligence

An automated early-warning system designed to monitor global health sources and identify potential disease outbreak signals.

The project uses NLP, confidence scoring, anomaly detection, and source conflict detection to analyze public health information.

**Category:** Bioinformatics & AI

---

### 🩸 Anemia Severity Classification & Hospital Recommendation System

A machine learning project that uses CBC data to classify anemia type and severity.

The project includes a preprocessing and evaluation pipeline along with a hospital recommendation interface.

**Technology:** Random Forest, Machine Learning, Python

---

### 🧬 Bio-Sequence Translation Tool

A desktop bioinformatics application for biological sequence analysis.

Features include:

- DNA-to-RNA transcription
- Reverse complement
- Protein translation
- Six-frame ORF detection
- FASTA import/export
- GUI-based interface

**Category:** Bioinformatics
